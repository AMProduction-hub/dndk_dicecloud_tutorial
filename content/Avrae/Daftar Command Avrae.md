# Avrae Commands

## 🎲 Dice & Rolling
Command yang berhubungan dengan dadu dan perhitungan.
### `!roll`

Melakukan roll dadu.

**Syntax:**

```
!roll <dice>
```

**Contoh:**

```
!roll 1d20
!roll 2d6+3
!roll 1d20+5
```
## 🧙 Character
Command untuk mengelola dan melihat character.
### `!character`

Melihat atau mengganti character aktif.

**Syntax:**

```
!character [name]
```

**Contoh:**

```
!character
!character MyCharacter
```
